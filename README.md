# Lease Intelligence Platform

Commercial lease ingestion, LLM extraction, and deterministic risk alerting for corporate real estate portfolios.

## Architecture

```
                        ┌─────────────────────────────┐
  browser ──────────▶   │  gateway (nginx) :8080      │
                        │  /            → web         │
                        │  /api/auth/*  → extraction  │
                        │  /api/*       → extraction  │
                        │  /api/alerts* → risk-engine │
                        └──────┬──────────────┬───────┘
                               │              │
              ┌────────────────▼───┐   ┌──────▼────────────┐
              │ extraction-svc      │   │ risk-engine       │
              │ Python 3.12 FastAPI │   │ Java 21 Spring    │
              │ LangChain + Claude  │   │ Boot 3, @Scheduled│
              │ pgvector Q&A        │   │ deterministic     │
              └────────────┬────────┘   └──────┬────────────┘
                           │                   │
                        ┌──▼───────────────────▼──┐
                        │ Postgres (Neon, pgvector)│
                        │ single source of truth   │
                        └──────────────────────────┘
  web = React (Vite + TS) static build, served by gateway
```

- **No Kafka, no k8s.** An append-only `events` table behind an `EventPublisher` interface stands in for a broker. The interface is the design decision; a broker is an ops decision.
- **5 containers**: gateway, extraction-svc, risk-engine, web (build stage), postgres (local only; Neon in prod).


## Tradeoffs (demo vs production)

- **PDF storage (D11):** Lease PDFs live on the local filesystem at `STORAGE_DIR/<sha256>.pdf`, keyed by content hash — no blob column in Postgres. On Railway the filesystem is ephemeral; seed PDFs ship in the image and re-ingest on boot. User-uploaded leases need re-upload after redeploy. Production path: object storage (S3 key = content hash).
- **Obligations on re-extraction (D13):** Obligations are delete-and-recreated per lease on each successful extraction. That cascades to alerts for the lease, so acknowledged alert state is lost and the risk engine re-raises on its next sweep — deterministic and idempotent, but not audit-preserving for alerts.
- **Seed:** Demo user seed runs every container boot (idempotent). Portfolio PDF seed runs only when the leases table is empty and `ANTHROPIC_API_KEY` is set.
